# Bore
Unity-based platformer 2d, inspired by the "Hollow Knight" series.
- **Amount of Players:** 1-2.
- **Languages of localisation:** English, Ukrainian, Polish.
- **Genre:** Platformer 2d, Co-op, Hardcore, Adventure.
